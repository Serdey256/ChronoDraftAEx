## 功能详情

### 1. 项目配置持久化 (`src/internal/config/config.go`)

- 配置文件存储在系统临时目录：`%TEMP%/chronodraftaex/config.json`
- 支持多项目管理，每个项目包含：
  - `id`: 唯一标识
  - `name`: 项目名称
  - `path`: 项目路径（绝对路径）
  - `description`: 可选描述
  - `is_active`: 是否活跃
  - `created_at`: 创建时间

### 2. 后端 API 新增方法

| 方法 | 说明 |
|:---|:---|
| `AddProject(name, path, description)` | 添加新项目并自动切换 |
| `SwitchProject(projectID)` | 切换到指定项目（重新初始化内核） |
| `RemoveProject(projectID)` | 删除项目 |
| `ListProjects()` | 列出所有项目 |
| `GetCurrentProject()` | 获取当前活跃项目 |

### 3. 动态项目切换

切换项目时会：
1. 更新配置文件中的活跃项目
2. 关闭当前 MemoryCore（释放数据库连接）
3. 使用新项目路径重新初始化 MemoryCore
4. 重新启动 MCP 服务器
5. 扫描新项目初始快照

### 4. 前端项目管理界面

- **Dashboard**: 顶部显示当前监控项目名称和路径
- **项目管理页面** (`/projects`):
  - 显示当前活跃项目（高亮）
  - 添加新项目（名称、路径、描述）
  - 切换项目
  - 删除项目

## 使用方式

1. 启动应用：`.\dev.ps1`
2. 点击左侧导航"📁 项目管理"
3. 点击"➕ 添加项目"
4. 输入：
   - 项目名称（如：MyWebApp）
   - 项目路径（如：`C:\Users\name\Projects\MyWebApp`）
   - 描述（可选）
5. 点击"确认添加"，自动切换到新项目
6. 返回仪表盘，点击"📥 捕获变更"开始监控

## 注意事项

1. 添加项目时路径必须存在，否则会报错
2. 切换项目时会重新初始化知识库，可能需要几秒钟
3. 每个项目有独立的知识库数据（存储在项目目录的 `.chronodraft` 中）
4. 配置存储在系统临时目录，重装系统会丢失
