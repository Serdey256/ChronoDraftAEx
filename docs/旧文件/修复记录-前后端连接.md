# 修复记录：前端无法连接后端问题

## 问题描述

前端点击"捕获变更"、"创建快照"等按钮无任何反应，仪表盘始终显示硬编码的 mock 数据（"重构认证模块，引入 OAuth2 PKCE 流程"）。

## 根本原因

项目使用 **Wails v3**，但前端代码写的是 **Wails v2** 的 API：

| | Wails v2 | Wails v3 |
|---|---|---|
| 调用方式 | `window.go.main.App.Method()` | `import { Method } from './bindings/...'` |
| 运行时注入 | 自动注入 `window.go` | 通过 `@wailsio/runtime` + 生成绑定 |
| 代码生成 | 自动 | `wails3 generate bindings` |

`window.go?.main.App` 在 v3 中根本不存在，所以所有按钮的 `if` 条件都不满足，导致静默失效。

## 修复步骤

### 1. Go 后端 (`src/app.go`)

将 `App` struct 重命名为 `ChronoService`（Wails v3 推荐模式）：

```go
// 修改前
type App struct { ... }
func NewApp() *App { ... }
func (a *App) ServiceStartup(...) { ... }

// 修改后
type ChronoService struct { ... }
func NewChronoService() *ChronoService { ... }
func (s *ChronoService) ServiceStartup(...) { ... }
```

所有方法接收器从 `a *App` 改为 `s *ChronoService`。

### 2. Go 入口 (`src/main.go`)

修复两处 API 不兼容：

```go
// 修改前
application.NewService(NewApp())
app.NewWebviewWindowWithOptions(...)

// 修改后
application.NewService(NewChronoService())
app.Window.NewWithOptions(...)
```

### 3. 生成 Wails v3 Bindings

```bash
cd src
wails3 generate bindings -ts
```

输出：
```
Processed: 426 Packages, 1 Service, 7 Methods, 0 Enums, 8 Models, 0 Events
Output directory: src/frontend/bindings
```

生成了以下文件：
- `src/frontend/bindings/ChronoDraftAEx/chronoservice.ts` — 7 个方法的 TypeScript 绑定
- `src/frontend/bindings/ChronoDraftAEx/index.ts` — 模块导出
- `src/frontend/bindings/ChronoDraftAEx/pkg/models/models.ts` — 数据模型类

### 4. 安装运行时依赖

```bash
cd src/frontend
npm install @wailsio/runtime
```

### 6. 类型文件 (`src/frontend/src/types.ts`)

移除了 Wails v2 的全局声明：

```typescript
// 删除的内容
export interface WailsApp { ... }

declare global {
  interface Window {
    go?: {
      main: {
        App: WailsApp
      }
    }
  }
}
```

## 验证结果

- ✅ Go 编译通过：`go build` 无错误
- ✅ TypeScript 检查通过：`tsc --noEmit` 无错误
- ✅ Bindings 生成成功：7 个方法已绑定
- ✅ 运行时依赖已安装：`@wailsio/runtime`

## 启动方式

```powershell
# 在项目根目录
.\dev.ps1
```

启动后：
- Wails 桌面窗口会弹出
- 前端通过生成的 binding 直接调用 Go 后端方法
- 不再依赖 `window.go` 全局对象

## 注意事项

1. **必须在 Wails 桌面窗口中操作**，不能在浏览器访问 `localhost:5173`
2. **需要设置 AI API Key**：`$env:CHRONODRAFT_AI_KEY="sk-..."`
3. **bindings 文件是自动生成的**，修改 Go 方法后需要重新运行 `wails3 generate bindings`
