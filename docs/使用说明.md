# ChronoDraftAEx 使用说明

> AI 编码时代项目知识的「黑匣子」— 结构化记忆与上下文管理系统

---

## 概述

ChronoDraftAEx 采用**双轨架构**：

| 轨道 | 载体 | 用途 |
|:---|:---|:---|
| **人类使用** | Wails 桌面应用 (`chronodraft-gui`) | 可视化仪表盘、知识图谱、项目管理 |
| **Agent 使用** | MCP stdio 服务器 (`chronodraft-mcp`) | AI 编辑器通过 MCP 协议访问知识库 |

两轨共享同一份 SQLite 数据存储，互不干扰。

---

# 第一部分：人类使用（Wails 桌面应用）

## 1. 环境准备

### 1.1 设置 AI API Key（必须）

```powershell
# PowerShell
$env:CHRONODRAFT_AI_KEY="sk-你的-api-key"
$env:CHRONODRAFT_AI_BASE="https://api.openai.com/v1"   # 可选，默认 OpenAI
$env:CHRONODRAFT_AI_MODEL="gpt-4o"                       # 可选
```

```bash
# Linux/macOS
export CHRONODRAFT_AI_KEY="sk-你的-api-key"
export CHRONODRAFT_AI_BASE="https://api.openai.com/v1"
export CHRONODRAFT_AI_MODEL="gpt-4o"
```

> 不配置 API Key 时，AI 摘要功能不可用，其他功能正常。

### 1.2 启动应用

```powershell
# 方式一：使用开发脚本
.\dev.ps1

# 方式二：直接使用 Wails
cd src
wails3 dev
```

启动后会弹出桌面窗口，前端页面同时在 `http://localhost:5173` 可访问。

## 2. 核心功能

### 2.1 仪表盘 (`/`)

**查看知识条目**
- 启动后自动加载已有知识条目
- 支持关键词搜索（语义搜索，依赖向量嵌入）

**捕获变更**
1. 在外部编辑器（VS Code / Cursor 等）修改项目文件
2. 回到 ChronoDraftAEx 窗口
3. 点击「📥 捕获变更」按钮
4. 系统自动：扫描文件 → AI 生成摘要 → 索引到知识库 → 更新仪表盘

**自动监控**
- 点击「启动监控」按钮开启文件系统监听
- 开启后，文件变动会自动触发捕获（2 秒防抖）
- 仪表盘每 5 秒自动刷新显示新条目

### 2.2 知识图谱 (`/graph`)

- 力导向图可视化展示知识实体关联
- 节点类型：条目(entry)、文件(file)、标签(tag)、模块(module)
- 支持拖拽交互

### 2.3 项目快照 (`/snapshot`)

- 创建项目版本快照（自动检测依赖）
- 对比不同快照的依赖变化
- 快照数据存储在 `.chronodraft/` 目录

### 2.4 项目管理 (`/projects`)

- 添加外部项目进行监控
- 切换当前活跃项目
- 删除项目
- 每个项目有独立的知识库数据

## 3. 数据目录结构

```
你的项目/
├── .chronodraft/
│   ├── last_snap.json      # 文件快照（变更检测基准）
│   ├── snapshot.json        # 项目快照
│   ├── vectors.db           # 向量数据库
│   ├── graph.db             # 图数据库
│   └── metadata.db          # 元数据库
└── AGENTS.md                # 自动生成的知识快照（供 AI 读取）
```

# 第二部分：Agent 使用（MCP 协议）

## 1. 构建 MCP 服务器

```bash
cd src
go build -o chronodraft-mcp.exe ./cmd/mcp    # Windows
go build -o chronodraft-mcp ./cmd/mcp         # Linux/macOS
```

## 2. 环境变量

| 变量名 | 说明 | 默认值 |
|:---|:---|:---|
| `CHRONODRAFT_PROJECT_ROOT` | 要监控的项目根目录 | 当前工作目录 |
| `CHRONODRAFT_AI_KEY` | AI API Key | （空） |
| `CHRONODRAFT_AI_BASE` | AI API Base URL | `https://api.openai.com/v1` |
| `CHRONODRAFT_AI_MODEL` | AI 模型名称 | `gpt-4o` |

## 3. Claude Desktop 配置

编辑配置文件：
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`
- **macOS**: `~/.claude/claude_desktop_config.json`
- **Linux**: `~/.claude/claude_desktop_config.json`

```json
{
  "mcpServers": {
    "chronodraft": {
      "command": "C:\\path\\to\\chronodraft-mcp.exe",
      "env": {
        "CHRONODRAFT_PROJECT_ROOT": "C:\\path\\to\\your\\project",
        "CHRONODRAFT_AI_KEY": "sk-..."
      }
    }
  }
}
```

## 4. Cursor 配置

在项目根目录创建 `.cursor/mcp.json`：

```json
{
  "mcpServers": {
    "chronodraft": {
      "command": "/path/to/chronodraft-mcp",
      "env": {
        "CHRONODRAFT_PROJECT_ROOT": "/path/to/your/project",
        "CHRONODRAFT_AI_KEY": "sk-..."
      }
    }
  }
}
```

## 5. 可用工具

### `search_knowledge`
搜索项目知识库，返回相关条目。

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|:---|:---|:---|:---|:---|
| `query` | string | ✅ | — | 搜索关键词 |
| `top_k` | int | ❌ | 10 | 返回结果数量 |

### `get_snapshot`
获取项目知识快照（AGENTS.md 格式），无需参数。

### `get_graph`
获取知识图谱数据（节点和边）。

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|:---|:---|:---|:---|:---|
| `limit` | int | ❌ | 100 | 最大节点数 |

### `list_entries`
分页列出知识条目。

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|:---|:---|:---|:---|:---|
| `offset` | int | ❌ | 0 | 起始位置 |
| `limit` | int | ❌ | 20 | 返回数量 |

### `capture_changes`
捕获文件变动并生成结构化知识条目。

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|:---|:---|:---|:---|:---|
| `session_id` | string | ❌ | "mcp-auto" | 会话 ID |

> ⚠️ `capture_changes` 需要有效的 AI API Key 才能生成结构化摘要。

## 6. 使用示例

### 在 Claude Desktop 中使用

配置完成后，Claude 会自动发现 ChronoDraftAEx 的 5 个工具。对话示例：

```
用户：帮我看看这个项目最近做了哪些改动
Claude：[调用 get_snapshot 工具]
       根据项目知识快照，最近的改动包括...

用户：搜索关于"认证模块"的知识
Claude：[调用 search_knowledge 工具, query="认证模块"]
       找到以下相关条目...

用户：记录一下刚才的代码修改
Claude：[调用 capture_changes 工具]
       已捕获变更并生成知识条目：...
```

# 附录

## 故障排查

| 问题 | 原因 | 解决方案 |
|:---|:---|:---|
| AI 摘要失败 | API Key 无效或未设置 | 检查 `CHRONODRAFT_AI_KEY` 环境变量 |
| 捕获变更无反应 | 未检测到文件变动 | 确认已修改项目文件 |
| MCP 工具返回空 | 知识库无数据 | 先通过 GUI 运行一次「捕获变更」 |
| Claude Desktop 无法连接 | 配置文件路径错误 | 检查 `claude_desktop_config.json` 路径和格式 |
| 知识图谱为空 | 无知识条目 | 先捕获一些变更数据 |
